# VedX — Showcase Website

> Showcase website for the VedX offline AI assistant for blind users.  
> Built with React + Vite.

**Live project repo:** https://github.com/yugalkishor-agi/Blind-Vision-Assistant

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Output goes to `dist/` — deploy it on Vercel, Netlify, or GitHub Pages.

## Deploy on Vercel (one click)

1. Push this folder to a new GitHub repo
2. Go to [vercel.com](https://vercel.com) → New Project → Import that repo
3. Framework: **Vite** — Vercel detects it automatically
4. Click Deploy ✓

## Deploy on GitHub Pages

```bash
npm run build
# then push the dist/ folder to gh-pages branch
```

Or add `vite-plugin-gh-pages` for automated deploys.
